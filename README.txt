STAR COMMUNICATION ISP ADMIN V15 - INSTALL READY

GitHub Pages:
1. Upload ALL 4 files from this folder to the GitHub repository ROOT.
2. Do NOT create public/public.
3. GitHub Pages should publish the root index.html.
4. Open the GitHub Pages address in Chrome.
5. Login with your real backend admin account.
6. For Android installation: Chrome menu -> Add to Home screen / Install app.

Included:
- Dashboard
- Customers
- Paid / Unpaid / Expired / Inactive
- Payment history & bill collection
- Due control
- New connections
- Income / Expense / Profit
- Backup
- MikroTik page
- V-SOL OLT page
- Settings
- PWA install support

Backend API default:
https://star-communication-v14-backend.onrender.com/api

NOTE:
The UI is ready for MikroTik and OLT configuration, but actual live device control requires the backend to have device-control routes and network access to the devices.
